# TaskFlow

A very simple to-do list app built with plain HTML, CSS, and JavaScript.
No frameworks and no libraries. It's a small project for learning Git and GitHub.

## Features

- Add tasks (empty tasks are ignored)
- Mark tasks as completed with a checkbox
- Delete tasks
- Tasks are saved in your browser (LocalStorage), so they survive a refresh
- Dark theme with a blue accent, works on phones and desktops

## How to run

1. Download or clone this project.
2. Open `index.html` in any web browser (double-click it).

That's it. There is nothing to install.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The structure of the page |
| `style.css` | The look: colors, spacing, layout |
| `script.js` | The behavior: add, complete, delete, save |

## Note

Tasks are stored only in your own browser, so they are not shared between devices.
